# lessonplan

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.9%2B-brightgreen.svg)](pyproject.toml)

给老师用的教案排版工具：按「小节：」写一份纯文本，一条命令生成干净、可直接打印的 A4 教案。**零依赖，不联网，打印即用。**

标题、科目、班级、课时自动排到页首，教学目标、重难点、教学过程、板书设计等小节按顺序展开，正文保留换行，适合把平时积累的教案统一成规范格式。

## 特性

- **分节书写**：`课题：`、`教学目标：`、`教学过程：` 等小节，正文直到下一个小节
- **常见的节名**：教学目标、重点、难点、准备、过程、板书、作业、反思都能直接识别
- **自定义小节**：不在预设里的节名，写成独立一行「拓展：」也能识别
- **正文保留换行**：教学过程里的「导入：」「新授：」不会误判成小节
- **元信息**：科目、班级、课时自动排到标题下方，`--teacher`、`--date` 可补执教与日期
- **编码兼容**：UTF-8（含 BOM）与 GBK 自动识别
- **逐行校验**：重复小节、空小节、没有课题、正文跑到小节外都会指出具体行号
- **55 个单元测试**：覆盖文本解析、字段校验、编码识别、渲染与命令行

## 安装

```bash
pip install lessonplan
```

也可以直接下载源码，在项目目录里运行：

```bash
python -m lessonplan --help
```

## 用法

准备 `教案.txt`：

```text
课题：光合作用
科目：生物
班级：初一（2）班
课时：1 课时

教学目标：
1. 说明光合作用的原料、条件和产物。
2. 能写出光合作用的文字表达式。

教学过程：
一、导入（5 分钟）
播放植物生长的延时视频。

二、新授（25 分钟）
讲解绿叶在光下制造有机物的实验。
```

生成教案：

```bash
python -m lessonplan -i 教案.txt --teacher 王老师 --date 2026-11-21 -o 教案.html
```

### 参数

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-i, --input` | 教案文本文件 | 必填 |
| `-o, --output` | 输出 HTML 路径 | `教案.html` |
| `--title` | 覆盖课题标题 | 使用文件中的课题 |
| `--teacher` | 执教老师，显示在信息行 | 空 |
| `--date` | 日期，例如 `2026-11-21` | 空 |

### 文本格式

- 第一行建议写 `课题：光合作用`
- `科目：`、`班级：`、`课时：` 是元信息，不会单独成节
- 小节标题以 `：` 或 `:` 结尾，内容写到下一个小节为止
- 预设小节：教学目标、教学要求、教学重点、教学难点、教学准备、学情分析、教学过程、教学活动、设计意图、板书设计、作业布置、课后作业、教学反思、教学小结、评价方式
- 其他节名只要单独占一行，例如 `拓展：`，也可以使用
- 正文里的「导入：播放视频」这类句子不会被当成新小节
- 编码支持 UTF-8（含 BOM）与 GBK

## 打印

用浏览器打开生成的 HTML，按 `Ctrl/Cmd + P`：

- 纸张：A4 纵向
- 边距：无 / 默认
- 勾选「背景图形」，小节左侧的竖线才会打印

内容较多时浏览器会自动分页，页脚统计正文总字数与小节数。
